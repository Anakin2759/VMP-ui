## 当前扫描结论

- 已确认 `IResourceProvider` 当前持有 `utils::Logger*`，默认 Provider 在 `GetDefaultUiResourceProvider()` 中使用函数静态 `shared_ptr`，存在跨 Runtime Logger 悬空风险。
- 已确认 `MpscQueue::TryEmplaceBeforePublish()` 在 CAS 占位后执行可能抛出的 `std::construct_at()`，当前 concept 未限制 noexcept，存在槽位永久空洞风险。
- 已确认 `src/api/Log.cpp` 的 `SetFilePath()` 与 `LogImpl()` 调用 `UiRuntime::current()`，且外部日志会转发至 Runtime 内部 Logger；P0-5a 可先做职责解耦，不触碰全部公共 API 签名。
- 已确认 `src/CMakeLists.txt` 中 OBJECT 库配置在 `find_package(X11 QUIET)` 之前读取 `X11_FOUND`，P0-4 具备明确的顺序修复候选。
- P0-5 全量 TLS 脱离涉及 `src/api` 多个公共自由函数和实体归属模型，超出安全小批次；本轮只评估真实范围并保留迁移路线，不进行大规模签名重构。
